# Code of Conduct

We want this project repository to remain a professional, respectful, and constructive environment for discussion, feedback, and collaboration.

## 1. Expected Behavior

Everyone interacting with this repository is expected to:

* Communicate respectfully and professionally.
* Provide constructive feedback.
* Respect the work and intellectual property of the project owners.
* Clearly identify and credit third-party resources when discussing or suggesting them.
* Report bugs and security concerns responsibly.
* Keep discussions relevant to the project.
* Respect the decisions and boundaries of the project owners.

## 2. Unacceptable Behavior

The following behavior is not permitted:

* Harassment, threats, bullying, or personal attacks.
* Discriminatory or offensive comments.
* Spam or intentionally disruptive behavior.
* Sharing private or confidential information.
* Attempting to gain unauthorized access to project resources.
* Maliciously modifying or interfering with project resources.
* Claiming the project or its original work as your own.
* Copying, reproducing, or redistributing project code without permission.
* Using substantial portions of this project in another academic or commercial project without written permission.
* Removing or modifying copyright and ownership notices.
* Uploading malicious code, malware, or intentionally harmful content.

## 3. Intellectual Property

This project is proprietary and is not an open-source project.

The `LICENSE` file defines the permitted and prohibited uses of the project's source code and original materials.

Respecting this Code of Conduct does **not** grant permission to copy, modify, distribute, or reuse the project.

## 4. Security Reports

If you discover a security vulnerability, do not publicly disclose sensitive technical details before the project owners have had an opportunity to review the issue.

Report security concerns privately to the project owners whenever possible.

Do not attempt to exploit a vulnerability beyond what is reasonably necessary to demonstrate the issue.

## 5. Issues and Discussions

Issues and discussions should be used for legitimate project-related purposes, such as:

* Bug reports
* Feature suggestions
* Technical questions
* Documentation improvements
* Development discussions

Unrelated promotional content, spam, or abusive discussions may be removed.

## 6. Enforcement

The project owners reserve the right to:

* Remove inappropriate content.
* Close or lock discussions and issues.
* Restrict participation.
* Block users who repeatedly violate this Code of Conduct.
* Take further action where necessary to protect the project and its contributors.

The project owners will make reasonable efforts to handle concerns fairly and professionally.

## 7. Scope

This Code of Conduct applies to interactions involving this project, including repository issues, discussions, pull requests, and other project-related communication spaces controlled by the project owners.

## 8. Final Statement

By interacting with this project, you agree to communicate respectfully and to respect the project's proprietary nature and intellectual property rights.

Thank you for helping maintain a professional environment.
